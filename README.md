# 🧟 Zombie Survival Game

A 2D Zombie Survival Game built with **Python** and **Pygame**, featuring real-time combat, wave-based enemy spawning, sprite-based graphics, and a modular object-oriented architecture.

This project is being developed as a portfolio project to demonstrate **Python programming**, **Game Development**, and **DevOps deployment** skills.

---

# 🎮 Gameplay

- Control the player using **W A S D** or **Arrow Keys**
- Aim using the **Mouse**
- Left Click to shoot
- Survive endless waves of zombies
- Eliminate zombies before they reach you

# ▶️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/zombie-survival-game.git
```

Go to project folder

```bash
cd zombie-survival-game
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the game

```bash
python src/main.py
```
